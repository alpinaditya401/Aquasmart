# Paket Laporan Progres AquaSmart AIoT

Paket ini disusun untuk Laporan Progres Blok 2026 kelas A pada 9 November 2026.

## Berkas

- `Laporan_Progres_AquaSmart_Blok_2026.docx` dan `.pdf` - laporan progres serta isian siap salin ke formulir.
- `SKPL_AquaSmart_V4.1_2026-11-09.pdf` - SKPL/SRS revisi status dan diagram; kebutuhan dan acceptance criteria V4.0 tetap menjadi baseline.
- `SKPL_V4.1_Revisi_2026-11-09.md` - sumber Markdown SKPL. Diagram yang dirujuk ada di folder `diagram/`.
- `Presentasi_Progres_AquaSmart_Blok_2026.pdf` dan `.pptx` - presentasi progres dan berkas PowerPoint yang dapat diedit.

## Catatan status

Progres 80% merupakan estimasi tim. Backend dan Flutter dilaporkan selesai oleh tim. Catatan uji yang ada bersifat historis; uji fisik perangkat, kalibrasi, validasi HP fisik, integrasi inferensi ML, dan uji end-to-end deployment masih perlu ditutup atau direkonsiliasi dengan bukti terbaru.
